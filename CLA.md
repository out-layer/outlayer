## How to sign

Post the following as a comment on your pull request:

```
I have read the CLA Document and I hereby sign the CLA
```

That comment, with your GitHub username and its timestamp, is the record of your
agreement. A maintainer verifies it is present before merging; there is no automated
check, so a pull request without it will simply not be merged.

Corporate contributors whose employer requires a signed Corporate CLA should contact
outlayer.ai@gmail.com before submitting a pull request.
